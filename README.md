# Hi, I'm William 👋

Applied AI product leader and hands-on builder. I turn frontier AI into products people actually adopt, and I build the systems that let a small team move like a big one.

I work *inside* the tools: designing AI architecture, shipping prototypes, and running a fleet of agents that handle real work. Three of those systems are open-sourced here.

Why share them now? Because they've crossed from prototype into daily operation. These are systems I actually run my work and my building on, refined over months of real use, not experiments I'm tossing over the wall.

### 🧭 [ai-chief-of-staff](https://github.com/willLin-creator/ai-chief-of-staff): orchestrating your work with agents
An operating system that turns an AI coding agent into a proactive chief of staff: inbox triage, tasks against goals, meeting processing, a relationship CRM, a **second brain** that compounds across sessions, and **autonomous agents** that run your day in the background. Distilled from 3,000+ hours of daily use.

### 🔁 [agent-harness](https://github.com/willLin-creator/agent-harness): loop engineering for building with agents
A language-agnostic generate → evaluate → fix harness for building software reliably with coding agents: sprint contracts, risk-tiered review depth, and loop closure. Built on Anthropic's harness-design pattern.

### 🧠 [agent-memory-vault](https://github.com/willLin-creator/agent-memory-vault): a self-auditing memory layer for agents
A file-based second brain for AI agents: a bounded hot-set index that stays cheap to load, recall by description so nothing is lost when a note falls out of the index, and a deterministic auditor that keeps the knowledge graph honest as it grows. Extracted from the second brain inside ai-chief-of-staff to stand on its own.
